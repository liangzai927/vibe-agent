设置

记忆（偏好、约定）和会话记录都存在项目之外—— 放项目里会让 git status 一直脏着。
默认在本机。想多台机器共享，就填一个 git 仓库地址。
当前解析为
填一个空白仓库的地址（SSH 或 HTTPS 都行）。 这是记忆和会话记录的仓库，不是你这个项目代码的 git 地址 ——代码该推哪儿还是推哪儿，两者互不相干。建议单独开一个 （比如 ai-memory）。
点下面的按钮会自动完成这些：
    仓库结构是固定的，先按项目分、项目下再分： 
    memory/                             全局偏好（所有项目都读）
projects/<项目名-哈希>/memory/        这个项目自己的偏好
projects/<项目名-哈希>/sessions/      这个项目的对话记录
    记忆会在每次对话时自动读进上下文。两级作用域： 「全局」所有项目都读，「本项目」只有当前项目读。
    设计稿和需求文档常常不在项目里。这条策略只管「读」——写操作永远锁在工作区内。
    ⚠ 「全部」意味着 agent 可以读这台机器上任何位置的图片和文档， 不会再问。介意的话选「只允许下面列出的目录」。
    用来读懂设计图上的文字和语义。留空的话，主模型自己能读图就沿用主模型。 可以在 /models 里看哪些标着「可读图」。
